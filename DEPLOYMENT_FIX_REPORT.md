4. Login and `auth/me` flow (example):

```bash
# Login (adjust payload keys to match your API)

# Extract token and call /auth/me
curl -v -H "Authorization: Bearer <ACCESS_TOKEN>" https://<your-backend>/api/auth/me
```

Expected: `/api/auth/login` returns 200 (or 201 depending on API), response contains `access_token`; `/api/auth/me` returns user object and permissions.

5. Verify permissions and ProtectedRoute behavior
